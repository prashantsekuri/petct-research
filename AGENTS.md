# Repository Instructions

This repository contains research tooling, not a clinical diagnostic system.

## Mandatory data-safety rules

- Source patient data must remain outside this Git repository.
- Treat every original DICOM study as read-only.
- Never modify, rename, delete, anonymize, or write into a source DICOM
  directory.
- Never upload patient data or send it to external services.
- Write derived artifacts only beneath the local `output/` directory, whose
  contents are excluded from Git.
- Never export all DICOM tags. Define and enforce an explicit metadata allowlist
  before metadata export is implemented because DICOM metadata can contain PHI.
- Do not rely on filename ignore rules as the primary data-control mechanism.
  DICOM objects can have no extension; keeping source data outside the repository
  is the actual protection boundary.

## Quantitative integrity

SUV, lesion size, coordinates, volume, radiomics, and other quantitative values
must be generated by deterministic imaging code. An LLM must never invent,
adjust, replace, or otherwise modify those values. Any future LLM stage must be
optional and limited to interpreting an evidence package produced by the
deterministic pipeline.

## Current scope

Maintain a minimal Python src-layout project using pytest. Do not add DICOM
discovery or processing, medical AI models, segmentation logic, or LLM
integration until explicitly requested.
